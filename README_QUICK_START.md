# 🚀 دليل التشغيل السريع

## تشغيل المشروع

### الطريقة 1: باستخدام main.py (موصى بها)
```bash
python main.py
```

### الطريقة 2: باستخدام run.py (نفس النتيجة)
```bash
python run.py
```

## ماذا يحدث عند التشغيل؟

✅ **يتم تشغيل:**
1. **الموقع (Flask)** على `http://localhost:8080`
   - يعمل في thread منفصل
   - واجهة المكتبة والاستفسار الذكي

2. **بوت التليجرام** في thread الرئيسي
   - يعمل بطريقة polling
   - يستقبل الرسائل ويرد عليها

## معلومات مهمة

### تسجيل الدخول
- **اسم المستخدم:** admin
- **كلمة المرور:** admin123

### فحص حالة البوت
بعد فتح الموقع، ستجد مؤشر حالة البوت في الصفحة الرئيسية:
- ✅ أخضر = البوت متصل وجاهز
- ❌ أحمر = البوت غير متصل (تحقق من BOT_TOKEN)

### إيقاف التطبيق
اضغط `Ctrl+C` في الترمينال لإيقاف كل من:
- الموقع
- البوت

## استكشاف الأخطاء

### البوت لا يعمل؟
1. تحقق من أن `BOT_TOKEN` موجود في ملف `.env`
2. تأكد من أن التوكن صحيح من BotFather
3. شاهد سجلات الأخطاء في الترمينال

### الموقع لا يفتح؟
1. تأكد من أن المنفذ 8080 غير مستخدم
2. جرّب تغيير `PORT` في `.env`
3. تحقق من أن جميع المكتبات مثبتة

### قاعدة البيانات فارغة؟
1. تأكد من وجود مجلد `db/` مع قاعدة ChromaDB
2. شغّل سكريبت السحب إذا كانت قاعدة البيانات جديدة
