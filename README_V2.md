## 📝 خطوات التشغيل (للمطور)

### الخطوة 1: تثبيت المكتبات الجديدة

```bash
pip install -r requirements.txt
```

أو تثبيت المكتبات الجديدة فقط:
```bash
pip install googlesearch-python beautifulsoup4 httpx
```

---

### الخطوة 2: إضافة المتغيرات الجديدة في `.env`

افتح ملف `.env` وأضف:

```env
# === V2: المصادر المتعددة ===
# رابط أو معرّف جروب الإقامات (يجب أن يكون حسابك منضماً له)
ACCOMMODATIONS_GROUP_ID=https://t.me/+ABC123xyz  # غيّر هذا بالرابط الحقيقي

# === V2: الخطة البديلة ===
# موقع الأزهر الرسمي (للبحث فيه عند فشل تليجرام)
AZHAR_WEBSITE_URL=azhar.eg/education-sector  # أو الموقع المناسب
```

> **⚠️ مهم جداً**: يجب أن يكون حسابك (المستخدم في `anon.session`) **منضماً** لجروب الإقامات الخاص، وإلا سيفشل السحب.

---

### الخطوة 3: بناء قاعدة البيانات بالمصادر الجديدة

#### أ) إذا كانت لديك قاعدة بيانات قديمة:

**خيار 1: إضافة المصدر الجديد فقط (موصى به)**

قم بتعديل ملف `scraper.py` مؤقتاً لاستخدام `scrape_all_sources()`:

```python
# في main.py - دالة setup_database_once()
# استبدل هذا السطر:
documents = await scraper.scrape_channel()

# بهذا السطر:
documents = await scraper.scrape_all_sources()
```

ثم شغّل البوت. سيضيف الرسائل الجديدة من جروب الإقامات **دون حذف القديم**.

**خيار 2: إعادة بناء كاملة (نظيف)**

احذف مجلد `./db` وشغّل البوت من جديد. سيسحب كل شيء من الصفر.

```bash
# Windows
rmdir /s /q db

# Linux/Mac
rm -rf ./db
```

### الخطوة 4: اختبار الميزات الجديدة

#### اختبار 1: البحث الذكي في الإقامات
اسأل البوت سؤالاً يحتوي على كلمة "إقامة":
```
"ما هي شروط الإقامة في المعهد؟"
```

يجب أن يبحث البوت **أولاً** في جروب الإقامات.

#### اختبار 2: الخطة البديلة (البحث في الويب)
اسأل سؤالاً **غريب** لن يجده في تليجرام:
```
"ما هي شروط القبول في معاهد الأزهر الثانوية 2026؟"
```

يجب أن يفشل البحث في تليجرام، ثم يبحث في الموقع الرسمي تلقائياً.

## 🔍 آلية عمل البوت V2

### 1. البحث الذكي (الأولوية للمصادر المتخصصة)
```
سؤال: "أين مبنى الإقامة؟"
        ↓
   يكتشف كلمة "إقامة"
        ↓
يبحث في جروب الإقامات أولاً (10 نتائج)
        ↓
    + يبحث في منشورات الأدمن (5 نتائج)
        ↓
    + يبحث في نقاشات الطلاب (5 نتائج)
        ↓
      يجمع النتائج ويرسلها لـ Gemini
```

### 2. الخطة البديلة (عند الفشل)
```
البحث في تليجرام فشل؟
        ↓
   يرسل رسالة انتظار للمستخدم
        ↓
يبحث في Google عن: "site:azhar.eg/education-sector {السؤال}"
        ↓
    يسحب أفضل 3 نتائج من الموقع
        ↓
      يُعطيها لـ Gemini للتحليل
        ↓
    يرد بإجابة من الموقع الرسمي
```

## 🐛 استكشاف الأخطاء

### خطأ: "تخطي مصدر فارغ: accommodations"
- **السبب**: لم تضف `ACCOMMODATIONS_GROUP_ID` في `.env`
- **الحل**: أضف الرابط أو المعرّف في `.env`

### خطأ: "فشل سحب المصدر... تأكد أن حسابك منضم"
- **السبب**: حسابك غير منضم للجروب الخاص
- **الحل**: انضم للجروب بحسابك الشخصي (المستخدم في `anon.session`)

### خطأ: "مكتبة googlesearch-python غير مثبتة"
- **الحل**: `pip install googlesearch-python`

### البوت لا يستخدم الخطة البديلة أبداً
- **السبب**: البحث في تليجرام ينجح دائماً
- **الاختبار**: اسأل سؤالاً غريباً لن يجده في القناة
