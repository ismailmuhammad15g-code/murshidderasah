# 🤖 بوت مرشد الدراسة - نظام RAG الذكي

## 📋 نظرة عامة

تم تطوير البوت ليشمل نظام **RAG (Retrieval-Augmented Generation)** ذكي يستخدم:
- ✅ **Google Gemini API** للإجابة الذكية
- ✅ **ChromaDB** لقاعدة بيانات المتجهات (خفيفة الوزن)
- ✅ **Telethon** لسحب الرسائل من القناة الرسمية
- ✅ **تجنب المكتبات الثقيلة** (لا torch ❌)

---

## 🎯 الميزات الجديدة

### زر "❓ طرح استفسار"
عند الضغط على هذا الزر:
1. يطلب البوت من الطالب كتابة سؤاله
2. يظهر "جارٍ الكتابة..." (typing action)
3. يبحث في قاعدة معرفة مستخرجة من القناة الرسمية
4. يستخدم Gemini لصياغة إجابة دقيقة بناءً على **الأدلة فقط**
5. يرسل الإجابة مع روابط المصادر

---

## 🛠️ متطلبات التشغيل

### 1. المكتبات المطلوبة
```bash
pip install -r requirements.txt
```

المكتبات الرئيسية:
- `python-telegram-bot==20.0`
- `google-generativeai`
- `chromadb`
- `telethon`

### 2. المفاتيح المطلوبة

#### أ. Google API Key
1. انتقل إلى: https://aistudio.google.com
2. سجل دخول بحسابك في Google
3. انقر على "Get API Key"
4. انسخ المفتاح وضعه في ملف `.env`

#### ب. Telegram API (Telethon)
1. انتقل إلى: https://my.telegram.org
2. سجل دخول برقم هاتفك
3. انقر على "API development tools"
4. أنشئ تطبيق جديد واحصل على:
   - `api_id`
   - `api_hash`

## ⚙️ التكوين

### 1. إنشاء ملف `.env`
انسخ محتوى `.env.example` إلى ملف جديد `.env`:

```bash
cp .env.example .env
```

### 2. تعبئة المتغيرات

**مثال:**
```env
# البوت
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz

# Google AI
GOOGLE_API_KEY=AIzaSyABC123xyz...

# Telethon
TELEGRAM_API_ID=1234567
TELEGRAM_API_HASH=abcdef123456789...

# القناة
CHANNEL_USERNAME=mahadalazhar
DAYS_LIMIT=365
TOP_K_RESULTS=3

# قاعدة البيانات
DB_PATH=./db
```

## 🚀 التشغيل

### التشغيل المحلي (للتجربة)
```bash
python main.py
```

### التشغيل على استضافة مجانية (pella.app)
1. ارفع الملفات إلى السيرفر
2. تأكد من وجود `WEBHOOK_URL` في `.env`:
   ```env
   WEBHOOK_URL=https://your-domain.pella.app/webhook
   ```
3. شغل البوت:
   ```bash
   python main.py
   ```

## 📊 كيف يعمل النظام؟

### 1. **بناء قاعدة المعرفة** (مرة واحدة فقط)
عند التشغيل الأول، البوت:
- يسحب الرسائل من القناة (آخر 365 يوم)
- يحولها إلى embeddings باستخدام Google API
- يخزنها في ChromaDB (`./db/chroma.sqlite3`)

⚠️ **ملاحظة:** هذه العملية قد تستغرق وقتاً (10-30 دقيقة) بسبب حدود Google API.

### 2. **الإجابة على الأسئلة**
عند سؤال الطالب:
1. **البحث:** يبحث البوت عن أقرب 3 رسائل من القناة
2. **الصياغة:** يرسل السؤال + الأدلة إلى Gemini
3. **الرد:** يحصل على إجابة ذكية ويرسلها للطالب مع المصادر

## ⚠️ تحذيرات مهمة

### 1. حدود Google API
- API المجاني له حد يومي (~1500 طلب/دقيقة)
- الكود يحتوي على `time.sleep(65)` لتجنب الخطأ 429
- عند بناء قاعدة البيانات، كن صبوراً!

### 2. الأمان
- **لا تشارك** ملف `.env` أبداً
- احتفظ بالمفاتيح سرية
- لا ترفع `.env` إلى GitHub

### 3. الأداء
- ChromaDB خفيف ولا يحتاج GPU
- البوت يعمل على استضافة مجانية (مثل pella.app)
- تجنب torch لأنها ثقيلة جداً

## 🐛 حل المشاكل

### المشكلة 1: `KeyError: 'GOOGLE_API_KEY'`
**الحل:** تأكد من وجود المفتاح في `.env`

### المشكلة 2: `429 Too Many Requests`
**الحل:** انتظر 60 ثانية، الكود يعيد المحاولة تلقائياً

### المشكلة 3: قاعدة البيانات لا تُبنى
**الحل:** تحقق من:
- صحة `TELEGRAM_API_ID` و `TELEGRAM_API_HASH`
- صحة `CHANNEL_USERNAME`
- اتصالك بالإنترنت

### المشكلة 4: الذاكرة ممتلئة
**الحل:** 
- استخدم `DAYS_LIMIT=180` بدلاً من 365
- قلل عدد الرسائل المسحوبة
