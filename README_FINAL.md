### البوت (Telegram)
- 💬 استفسار ذكي مع RAG + Gemini
- 📰 آخر 5 أخبار رسمية
- 📚 إدارة المكتبة (رفع، تحميل، تقييم)
- 🔔 نظام الإشعارات
- 📊 إحصائيات شاملة
- 🔄 تحديث تلقائي كل 5 دقائق
- 🎯 10 مفاتيح Google API مع Round Robin

### الموقع (Flask)
- 📖 مكتبة إلكترونية متكاملة
- 🤖 استفسار ذكي مباشر
- 👥 نظام مستخدمين
- 📊 إحصائيات حية من البوت
- 🔍 مؤشر حالة البوت في الوقت الفعلي
- 📚 رفع وتحميل الكتب

## 🔧 الإعدادات المهمة

### ملف .env
يجب أن يحتوي على:
```env
BOT_TOKEN=your_bot_token_here
GOOGLE_API_KEY_1=key1
GOOGLE_API_KEY_2=key2
# ... حتى 10 مفاتيح
API_ID=your_api_id
API_HASH=your_api_hash
FLASK_SECRET_KEY=your_secret_key
```

### قاعدة البيانات
- `school_bot.db` - قاعدة بيانات البوت الرئيسية (SQLite)
- `db/` - قاعدة ChromaDB للبحث الذكي (Vector Store)

## 🚨 استكشاف الأخطاء

### مؤشر حالة البوت يظهر "غير متصل"
```bash
# تحقق من وجود قاعدة البيانات
dir school_bot.db

# إذا لم تكن موجودة، شغّل البوت أولاً
python main.py
```

### الإحصائيات تظهر 0
```bash
# تأكد من وجود بيانات في القاعدة
python check_db.py
```

### البوت لا يستجيب
1. تحقق من `BOT_TOKEN` في `.env`
2. تأكد من صلاحية التوكن من BotFather
3. شاهد السجلات في الترمينال

### الموقع لا يفتح
1. تأكد أن المنفذ 8080 غير مستخدم
2. جرّب `python run_both.py` بدلاً من تشغيلهما منفصلين
3. تحقق من السجلات
