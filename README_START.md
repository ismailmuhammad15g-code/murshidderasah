# 🚀 تشغيل البوت والموقع - دليل سريع

## ✅ كل شيء جاهز! فقط شغّل

### 🎯 الطريقة السهلة (مُوصى بها)

**انقر مرتين على:**
```
START.bat
```

**أو من الترمينال:**
```bash
python run_both.py
```

هذا سيشغل:
- 📱 البوت على Telegram
- 🌐 الموقع على http://localhost:8080

---

## 📋 ما تم إصلاحه

✅ **requirements.txt**
- حذف FAISS
- إضافة ChromaDB + APScheduler + hnswlib

✅ **main.py**
- تحديث APScheduler ليعمل بشكل صحيح
- إصلاح خطأ NoneType
- المهام الآلية مُفعّلة:
  - 🔄 التحديث كل 5 دقائق
  - 🧹 التنظيف اليومي عند 3 فجراً

✅ **vector_store.py**
- يستخدم ChromaDB (احترافي)
- البحث الهجين (admin + student)
- نظام الدوران للـ 10 مفاتيح

✅ **scraper.py**
- يصنف الرسائل (admin/student)
- يسحب من جميع المصادر

---

## 🎯 الميزات النشطة

### 1. التحديث الآلي (كل 5 دقائق)
- يسحب الرسائل الجديدة تلقائياً
- يضيفها لقاعدة ChromaDB
- بدون تدخل يدوي

### 2. التنظيف اليومي (3:00 صباحاً)
- يحذف الرسائل الأقدم من 365 يوم
- يحافظ على قاعدة البيانات نظيفة

### 3. نظام الدوران (10 مفاتيح)
- **في البناء**: كل دفعة تستخدم مفتاح مختلف
- **في الردود**: كل سؤال يستخدم المفتاح التالي
- **الفائدة**: سرعة 10x + 150 طلب/دقيقة

### 4. البحث الهجين الذكي
```
السؤال → يكتشف الكلمات المفتاحية
       ↓
       يبحث في admin (رسمي)
       ↓
       يبحث في student (سياق)
       ↓
       يجمع النتائج ويرسلها لـ Gemini
```
