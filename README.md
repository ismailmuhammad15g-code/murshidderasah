# 🎓 بوت مدرسة الأزهر الإعدادية (بنين)

بوت تليجرام متطور لإدارة المكتبة الرقمية والتواصل مع الطلاب - الصف الثاني الإعدادي

## ✨ الميزات الرئيسية

### 📚 للطلاب

#### 1. **المكتبة الرقمية المتقدمة**
- 📖 تصفح الكتب حسب الفئات (رياضيات، علوم، لغة عربية، إلخ)
- 🔍 بحث متقدم بالعنوان والموضوع
- 🔥 عرض الكتب الأكثر شعبية
- ⭐ عرض الكتب الأعلى تقييماً
- 📥 تحميل الكتب بصيغة PDF أو صور
- 👁️ عداد المشاهدات لكل كتاب

#### 2. **نظام التقييمات والمراجعات**
- ⭐ تقييم الكتب من 1 إلى 5 نجوم
- 💬 قراءة مراجعات الطلاب الآخرين
- 📊 عرض متوسط التقييم لكل كتاب
- 🔔 إشعار لصاحب الكتاب عند التقييم

#### 3. **نظام المفضلة**
- ⭐ حفظ الكتب المفضلة للوصول السريع
- 📚 عرض قائمة كاملة بكتبك المفضلة
- 🗂️ تصنيف المفضلة حسب الفئات

#### 4. **نظام الإشعارات الذكي**
- 🔔 إشعارات فورية عند الموافقة على كتبك
- 📢 إشعارات بالأخبار الجديدة
- ⭐ إشعار عند تقييم كتابك
- 💬 إشعار عند الرد على استفساراتك
- ✅ وضع علامة مقروء على الإشعارات

#### 5. **رفع ومشاركة الكتب**
- 📤 رفع كتب ومقالات خاصة بك
- 📝 إضافة عنوان ووصف للكتاب
- 🏷️ اختيار الفئة المناسبة
- ⏳ متابعة حالة الموافقة
- 📊 مشاهدة إحصائيات كتبك (تحميلات، تقييمات)

#### 6. **كتبي - إدارة مساهماتك**
- 📚 عرض جميع كتبك المرفوعة
- ✅ معرفة الكتب المعتمدة
- ⏳ متابعة الكتب بانتظار الموافقة
- 📊 إحصائيات التحميلات والتقييمات
- 🗑️ حذف كتبك الخاصة

#### 7. **الأخبار والتحديثات**
- 📰 متابعة آخر أخبار المدرسة
- 🕒 أخبار مؤرخة ومنظمة
- 📌 أخبار ذات أولوية

#### 8. **حالة الكتب الدراسية**
- 📚 معرفة إذا نزلت الكتب
- ⏰ آخر تحديث للحالة
- 📋 رسالة واضحة من الإدارة

#### 9. **الاستفسارات والدعم**
- 💬 إرسال استفسارات للإدارة
- 📧 إرسال تلقائي عبر البريد الإلكتروني
- ✅ تأكيد استلام الاستفسار
- 💌 الرد المباشر من الإدارة

#### 10. **المساعدة**
- ❓ دليل استخدام شامل
- 📞 معلومات الاتصال
- 💡 نصائح وإرشادات

### 🔧 للإدارة (Admin)

#### 1. **لوحة تحكم متقدمة**
- 📊 إحصائيات شاملة ومباشرة
- 👥 عدد المستخدمين
- 📚 عدد الكتب (معتمدة / بانتظار الموافقة)
- 📥 إجمالي التحميلات
- ⭐ عدد التقييمات

#### 2. **إدارة الأخبار**
- ➕ إضافة أخبار جديدة
- 📋 عرض جميع الأخبار
- ❌ حذف الأخبار
- 🔔 إرسال إعلانات جماعية

#### 3. **إدارة المكتبة**
- ✅ الموافقة على الكتب المرفوعة
- ❌ رفض الكتب غير المناسبة
- 📤 رفع كتب من الإدارة
- 🗑️ حذف كتب
- 🔔 إرسال إشعارات للطلاب

#### 4. **تحديث حالة الكتب الدراسية**
- 📚 تحديث رسالة حالة الكتب
- 🕒 تاريخ ووقت آلي
- 📢 إعلام الطلاب

#### 5. **إحصائيات تفصيلية**
- 📊 ملخص عام شامل
- 🔥 الكتب الأكثر شعبية
- ⭐ الكتب الأعلى تقييماً
- 👥 تحليلات المستخدمين

#### 6. **إرسال إعلانات جماعية**
- 📢 إرسال رسائل لجميع المستخدمين
- 📊 إحصائيات النجاح/الفشل
- 📝 تأكيد قبل الإرسال

#### 7. **الرد على الاستفسارات**
- 💬 الرد المباشر على استفسارات الطلاب
- 🎯 إرسال للمستخدم مباشرة
- 📝 سجل الاستفسارات

## 🚀 التثبيت والتشغيل

### المتطلبات
```bash
Python 3.8+
python-telegram-bot==20.0
python-dotenv==1.0.0
```

### خطوات التثبيت

1. **استنساخ المشروع**
```bash
cd schoolnewsbot
```

2. **تثبيت المتطلبات**
```bash
pip install -r requirements.txt
```

3. **إعداد ملف البيئة (.env)**
```env
BOT_TOKEN=your_bot_token_here
ADMIN_NAME=اسم الأدمن
ADMIN_EMAIL=admin@example.com

# Mail Configuration
MAIL_SERVER=smtp.gmail.com
MAIL_PORT=587
MAIL_USE_TLS=True
MAIL_USERNAME=your_email@gmail.com
MAIL_PASSWORD=your_app_password
MAIL_DEFAULT_SENDER=your_email@gmail.com
```

4. **تشغيل البوت**
```bash
python main.py
```

## 🔐 نظام الإدارة (Admin)

### تسجيل الدخول كأدمن

1. استخدم الأمر: `/admin_secret`
2. أدخل كلمة السر: `Admin_log`
3. أدخل اسمك (يجب أن يطابق ADMIN_NAME في .env)
4. أدخل بريدك الإلكتروني (يجب أن يطابق ADMIN_EMAIL في .env)

### الأوامر الإدارية

- `/admin_panel` - فتح لوحة التحكم
- `/approve [book_id]` - الموافقة على كتاب
- `/reject [book_id]` - رفض كتاب
- `/reply [user_id] [message]` - الرد على استفسار
